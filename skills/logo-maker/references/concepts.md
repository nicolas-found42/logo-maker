# Author a shortlisted concept

## Intake and references

Use the templates generated by `new`. For each missing palette, supply distinct
`[[palette]]` entries using `primary`, `secondary`, `accent`, `background`, `ink`, and optional
`highlight`. For missing fonts, supply `[[fonts]]` entries with `display` and `text` specs such as
`"Family:wght=600"` using actual Google Fonts families and supported axes. Let the brief guide the
contrast between options. Read `ideation/palette.json` for `dropped_wcag` and the picked values,
and `ideation/fonts.json` for the font pairing. If a chosen font cannot resolve, use the repair
named by intake for that proposal and cached choice.

A reference path is relative to the logo folder when stored as `inputs/name.png`. Keep the roles
explicit:

| `[[references]].use` | What to do with it |
|---|---|
| `style` | Use it to understand visual character. Intake judges the image and extracts color observations. |
| `geometry` | Derive paths only when the user owns or has licensed the artwork for this use. Intake records the reference. The agent traces or imports it in the motif authoring step. |
| `craft` | Use it as an execution-quality comparator. Write a `note` about the reference's own finish. The candidate's design and finish come from its brief. |

## When the object is the logo

Build the object itself when the brief calls for a cup, machine, mascot or product in 3D. Sketch
its silhouette and identify the openings, joins and functional parts that make it recognizable.
Use catalog components or build individual meshes and import them with `kind = "mesh"`. For a
cup, give the lip and interior real depth. Put the handle in a vertical plane through the cup's
axis. Attach it to the outer wall at two heights between the rim and the foot. Open a three-quarter
view that shows both joins and a second view that looks down into the cup. Check that the grip has
finger clearance and its ends do not protrude into the interior. Compare the handle's position and
opening to the flat mark. For an espresso maker, show the brew head, open bay and integrated tray
as parts of the housing. Put the same recognition cues in the flat motif for small uses. Add a
plaque or pedestal only when the brief calls for one. A reviewed production profile can cover
declared mesh inputs within its material and render scope.

For a freestanding product, keep its support surface horizontal in the editable scene and set the
hero angle with the camera. Check the model from the side as well as through the camera. With mesh
imports, inspect all parts together so the handle, body and liquid level share the same upright axis.

When curving a label onto an object, confirm the text orientation in the actual camera view.
Subdivide long triangles before projecting them onto the surface so letters and strokes follow the
curve. Inspect the whole mark for missing segments and test its small-size counterpart.

## From text direction to geometry

1. After `ideate`, run `plan` to generate templates and identify missing fields. Read each
   `concept.json` for the metaphor, treatment and material. Fill its `plan.toml` using the
   current frozen revision and requirement IDs. Follow [brief creation](brief-creation.md)
   for visual hypotheses, assumptions and the detail ledger. A valid plan establishes intent.
   When adapting a text proposal to a different material or construction, retain its original
   record outside the concept folder. Update `concept.json.description`, `treatment_text` and
   `material_text` for the design you actually build. In `plan.toml`, explain the actual parts,
   their contact points and what carries the load. Keep the concept ID so its history
   remains traceable. If the slate contains weak or unresolved directions, review all flat size
   sheets first. Retain the original shortlist and document why any directions are set aside.
   Keep distinct eligible directions for image comparison.
2. Write a [motif](motif-api.md) for each shortlisted folder. Build a recognizable silhouette,
   proportions and deliberate junctions. Keep the primary identity legible at 16 and 32 px.
   If a color boundary carries the identity, test the one-ink version. Give that boundary a
   deliberate opening or contour in the flat master so a single fill still shows it.
   Save as `motif.py` or supply a contract-clean `motif.svg`. A folder with `motif.py` owns its
   generated SVG. Use a different source folder or remove that script deliberately when switching
   to an authoritative SVG. For an imported raster reference, follow [flat assets](flat-assets.md)
   to obtain geometry, then map shape colors to deliberate material roles.
3. Run `motifs`. A successful first build writes the size sheets and starter scenes, then stops
   so you can tune them. Open the size sheets together. Improve the primary silhouette before
   polishing finishes. Choose each detail for the brief and the scale where it will appear.
4. Read the [scene grammar](scene-grammar.md#how-a-treatment-consumes-the-motif) for what the
   treatment builds from those paths. Extrusions need viable solid shapes, reliefs need clear
   margins, and tube treatments trace paths. Tune `scene.toml` for part materials, heights,
   bevels, framing, camera and light. Use `[mark].scale` to clear rims, recess walls and lettering.
   From the tool checkout consult `logo_maker/catalog/components.md` and
   `logo_maker/catalog/materials.toml` for supported parameters. A custom `scene.py` can support a
   study, but its custom Blender components are outside the production sampling profile contract.
5. Write `construction.json` using [refinement records](refinement.md). Update
   `concept.json.description` to its current description and declare external dependencies. Rerun
   `plan` after description or requirement edits and `motifs` after motif or scene edits.
   Advance when both pass on the current sources and you have opened the size sheets.

Test the riskiest visible relationship with one controlled change and compare the images. For
paper, check planes, folds and layering. For reflective material, check the edge separation and
whether reflections support the shape. Compare the actual silhouettes before finish variants.
Keep the flat and hero marks recognizable as the same symbol.
